# Pagham Beach Dashboard

This package contains four finished standalone background images:

- `images/morning.png`
- `images/day.png`
- `images/sunset.png`
- `images/night.png`

They contain no dashboard cards, labels, titles, icons or example figures.

The live HTML dashboard is layered over the images and switches between them automatically according to the time of day.

## Live data already connected

- Air temperature
- Modelled sea-surface temperature
- Wind speed
- Wind gusts
- Wind direction
- Windsurf category
- Sunset
- Remaining daylight

## To connect next

- Official tide data
- Environment Agency Pagham bathing-water data
- Official pollution alerts

## Test locally

Extract the ZIP and double-click `index.html`.

For the most reliable test, open the folder in Visual Studio Code and use the Live Server extension.

## Publish through GitHub Pages

Upload all the files and folders to the root of your GitHub repository. Enable Pages from the `main` branch and `/root` directory.
